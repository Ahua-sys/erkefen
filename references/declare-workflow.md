# 新建申报流程（第二课堂平台）

把本地截图提交为一条「新建申报」。前置：bsk CLI + Edge 扩展已装好并连接、Edge 已手动打开、扩展已开「允许访问文件网址」。
本流程可用 `scripts/declare.py` 一键复刻（见文末），本文档记录手工路径与所有坑。

## 一、路径（用户口述版）

1. 登录进入二课平台 `http://dierketang.gzhu.edu.cn/second_class_sj/home`
2. 点底部「**我的**」
3. 点「**我的申报**」磁贴（注意：入口叫"我的申报"，不是"活动申报"）
4. 点「**申请申报**」
5. 进入「**新建申报**」表单，按顺序填（下文）

## 二、表单填法（按用户规则）

| 字段 | 填法 |
|------|------|
| 学年学期 | 默认选最新的（实测唯一项「2025-2026 学年」） |
| 项目分类 | 选带 **【2025级】** 前缀的项（用户 2025 级）；分类据截图对应 |
| 申报学分 | 证明截图上的加分数值（如 0.1） |
| 项目名称 | 截图上的活动名称 |
| 是否为集体项目 | **否**（此字段在填完项目名称后才弹出） |
| 项目获奖自然年 | 按活动实际举办年份（2025 年内举办选 2025，2026 选 2026） |
| 申报说明/成绩/实习单位/实习时间/是否破记录 | 都不填 |
| 上传附件 | 对应的证明截图（jpg/png/jpeg/bmp/gif，单张 ≤500KB，最多 3 张） |
| 提交 | 点「确定申请」→ 回到「我的申报」列表，新记录审核状态「未审核」 |

## 三、登录（几乎每次都会被踢）

- 首页若停在「登录」页：页面上「统一身份认证登录」只是标签，**真正按钮是下方白色「统一身份认证」**，点它跳 CAS。
- CAS 无免密记忆，必须人工输学号密码 → 用 `bsk request-help` 请用户完成，完成后 `navigate` 回 home。
- 批量/长时间操作中 session 随时可能失效，表单填写会**全部丢失**，需整段重走——重要提交前先确认登录态新鲜。

## 四、踩坑记录（实测，2026-10-16 持续补充）

1. **vant picker 只能真实鼠标点击**：对 `.van-picker__confirm` 或选项 li 执行 JS `.click()` 完全无效；必须 `bsk click @ref`（ref 从 observe 解析），选项点完再点「确认」。
2. **上传必须先给扩展开「允许访问文件网址」**：Edge → `edge://extensions/` → BrowserSkill 详细信息 → 开启。没开时报 `Not allowed`（CDP -32000）。
3. **上传按钮别点错**：「上传图片」和「确定申请」是两个按钮，误点后者会直接提交空表单。
4. **observe 输出有两类行，解析时都不能丢**：
   - 交互元素带引用：`@e7 button "我的"`；
   - 结构节点**没有引用**：`RootWebArea "我的"`、`LabelText "申报学分"`、`paragraph "…"`。
   只用 `@e\d+` 正则解析会丢掉 RootWebArea → 「等页面变成某状态」的判断永远为假、必然超时（declare.py 真实栽过）。
5. **输入框定位用 LabelText，不要用 textbox 顺序或 [ctx:] 标注**：DOM 顺序虽然是 申报学分→项目名称→申报说明→成绩→实习单位→实习时间，但 textbox 自带的 `[ctx: …]` 标注不可靠（成绩/实习单位/实习时间的 ctx 都会显示"申报学分"）；以相邻的 `LabelText` 为准。
6. **弹窗有两种结构，处理方式不同**（2026-10-16 实测）：
   - picker（学年学期 / 项目获奖自然年 / 是否为集体项目）：有「取消/确认」，**点选项后弹窗不关，必须再点「确认」**；
   - 列表弹窗（项目分类）：无确认按钮，7 个分类平铺成 list，**点选项即选中并自动关闭**。
   弹窗是否打开可看 observe 头部：`@layers 2 focus=L1` + `L1 mask cover=100%`（正常页面是 `@layers 1` + `L1 page`）。
7. **ref 只在当次 observe 快照内有效**：picker 点确认后表单会异步重渲染（字段值更新），紧接着抓的 ref 可能瞬间失效，下一条命令报 `observation ref was not found`。对策：动作前重新 observe、失败就重试；脚本用 `with_fresh_ref()` 统一处理。
8. **底部 tab 点击要等页面加载完**，否则静默失效（还停在首页）；同理表单字段刚渲染出来时点击也可能无反应（Vue handler/基础数据未就绪），重试即可。
9. **服务端曾整体抽风**：`getReportBasisData` 返回「数据连接超时」时学年学期/分类下拉全空，只能过段时间再试（非操作问题）。
10. **daemon 自更新会把自已搞死**（沙箱环境）：0.3.1→0.3.3 时 detached update helper 被回收，`move` 报"拒绝访问"，daemon 退出后再也不回。解法：手动从 `api.github.com/repos/Tencent/BrowserSkill/releases/assets/<id>` 下载 zip（Accept: application/octet-stream）+ sha256 校验 + 覆盖 `~/.local/bin/bsk.exe`，再 `bsk daemon start --foreground`。

## 五、一键复刻（scripts/declare.py）

```bash
python scripts/declare.py --image "E:/Users/Ahua/Desktop/二课分/<截图>.jpg" \
    --project-name "2025年广州大学运动会" --credit 0.1 \
    --category "【2025级】体育运动与审美体验类" --year 2025 --collective no
```

- `--category` 也可用简写 `三创` / `体育` / `思政`（脚本自动映射 2025 级分类）。
- `--no-submit`：只填到上传后、不点提交，用于安全验证。
- 脚本自动处理：daemon/扩展前置检查、登录检测与 CAS 人工协助、两种弹窗的真实点击、ref 失效自动重试、上传、提交后校验（列表出现项目名）。
- 需要人工配合的点只有两个：Edge 保持打开；被踢登录页时在弹出的窗口里输学号密码。
